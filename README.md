# BookFinder

A full-stack Book Management and Ordering System developed using **Flutter**, **Node.js**, **Express.js**, and **MySQL**.

![image alt](https://github.com/Muhammad-ali850/BookFinder/blob/main/Screenshot.jpeg?raw=true)

BookFinder allows users to browse books, search for books, view basic information, and place orders through a mobile application. Administrators can manage books through secured API endpoints while users can manage their orders through the application interface.

---

## Features

### User Features

* User Registration
* User Login
* JWT Authentication
* Persistent Login using Shared Preferences
* Browse Available Books
* Search Books by Title
* View Book Details
* Place Orders
* View Orders
* Update Orders
* Delete Orders

### Admin Features

* Add Books
* Update Books
* Delete Books
* Manage Book Inventory through APIs
